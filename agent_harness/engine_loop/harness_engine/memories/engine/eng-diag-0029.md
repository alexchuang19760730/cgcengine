[engine] An instrument that exists to decide 'is the SAME thing really the same' must record the INDEX the consumer used in the same record as the digest of the data behind it, and the comparator must read the index field FIRST. A digest alone cannot separate two different defects: 'the two arms selected different indices' and 'the same index holds different data' both print as one word, DIFF. Print them side by side, write the branching decision rule into the comparator, and make the 'no difference' verdict state what it does and does not license. Corollary for the probe width: clamp the probe to the row stride, then report the clamped width -- if the width equals the stride, 'identical' is a statement about the whole row rather than about a prefix, and that is a strictly stronger claim for the same code.

## 為什麼（because）

The S1 localisation had been reduced to one sentence, 'the two arms consume the same ids and the same pool layout, yet the gathered bytes differ', and the pre-existing probe for it reads the weights from the HOST during graph ENCODING (op->src[0]->data + id*nb02). On the arm under investigation the ids are a graph-computed node, so at encode time that pointer is unfilled and the probe reports 16/16 out-of-range ids made of float bit patterns -- it tracks who last wrote the buffer, not what the consumer received. Moving the same read into the Metal kernel, submitted into the same encoder right after the consuming kernel, produced the answer on the first run: over 30 graphs, including the first single-token step, the selected slots hold byte-identical rows (probe = nb02 = 335872/450560 B), and on the 5 graphs where the rows differ the IDS differ. So the hypothesis the probe was built to test was refuted rather than confirmed -- and a digest-only instrument would have printed DIFF there and read exactly like a confirmation. Recording the id in each row is what prevented that false positive.

## 反例（counterexample_observed）

Two interleaved-free A/B runs of 36 graphs each, probe 4096 B and probe = whole row, both gave SAME=90 DIFF=15 NOT-READ=0 with FIRST DIFF at graph 31 (ffn_moe_down-1.pool) and a different id in row 0 of every differing pair; the same-arm control (one arm, twice) was 99/99 SAME at both probe widths. At the first single-token step the layer-1 ids are still identical while layer 0's attn_norm output already differs, so the divergence is introduced in layer 0 and the routing follows one step later.
