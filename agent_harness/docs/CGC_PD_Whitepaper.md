## 為什麼這個檔案變成指標（2026-09-17）

這個檔案與 `agent_harness/pd/CGC_PD_Whitepaper.md` 原本是**逐位元組相同**的兩份
（md5 `e1a34fac72c958ef2d688b5184a4a943`）。同一份文件的兩份副本就是**兩個真相**：
它們在下一次有人只改其中一份時分岔，而分岔之後兩邊都還是能開、都看起來正常。

處置**不是刪掉這一份**，因為那是破壞性的，而且 `docs/AGENT_HARNESS_E1_RESTRUCTURE_20260916.html`
引用過這個路徑 —— 刪掉會讓一份已定稿的文件說假話（本 repo 對已發表文件的立場是
**標註而不是改寫**）。所以改成指標：路徑仍然解析得到，而內容**只有一份**。

這與 `agent_harness/shared/trace_schema.md` 的做法相同（那份也「指向權威位置，刻意不重述」）。

同一個目錄下的 `DOPD_UPGRADE_PLAN.md` 是同一情況、同一處置。
`PD_INTEGRATION_DELIVERY.md` 沒有重複，仍留在這裡。
