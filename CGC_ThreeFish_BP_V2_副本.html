一、定位图：三维度市场空白

AI 推理市场的三个核心维度——延迟、数据主权、大模型能力—— 目前没有任何产品同时满足。CGC 是唯一占据左上角位置的架构。

市场缺口：左上角（低延迟 + 数据主权 + 大模型）是空的。CGC 是唯一架构能同时满足三个维度。

  • ChatGPT / DeepSeek / Copilot / Cursor / Claude：大模型能力强，但数据上传云端，无数据主权
  • 通义灵码 / Comate / Tabnine：有数据主权，但延迟 150-300ms，且只能跑小模型
  • Ollama（本地部署）：有数据主权，但 16GB 设备只能跑 2B 小模型，跑不了 26B+
  • CGC 三鱼模式：0.3-13ms TTFT + 数据不出域 + 26B 大模型能力，独占空白区

二、执行摘要

CGC（Compute Graph Compiler）是一个端云协同的 AI 推理引擎。核心创新在于： 同一套技术栈（MTP Draft + Hermes 智能路由 + Edge Proxy），同时解决三个市场痛点—— 企业的数据主权焦虑、用户的推理延迟痛点、以及终端设备跑不了大模型的能力鸿沟。 适用于代码补全、对话问答、文档摘要、RAG 检索等任意 LLM 推理场景。

核心论点：现有 AI 推理市场存在一个清晰的缺口——没有产品同时做到"低延迟 + 数据主权 + 大模型能力"。

  • ChatGPT / DeepSeek / Copilot / Cursor：大模型能力强，但数据上传云端，无数据主权
  • 通义灵码 / Comate / Ollama 本地部署：有数据主权，但延迟高或只能跑小模型
  • 所有云端方案：Mac/笔记本用户只能跑 2B 小模型，26B+ 大模型是云端专属

CGC 是唯一能占据这个缺口的架构。

三、三鱼模式

"一鱼两吃"升级为"三鱼模式"。同一套 MTP Draft（llama.cpp 路径）+ Hermes(SFT) 智能路由技术栈， 服务三个独立的产品价值维度。

鱼一：数据主权

~100%

数据不出域覆盖率

  • 缓存命中 (30%)：数据不出设备
  • 敏感数据 MISS：端侧 MTP 推理，不出域
  • 非敏感 MISS：云端 EP8，不出内网
  • Hermes(SFT)：语义级敏感度检测（非 regex）

鱼二：推理加速

128

本地 MTP crossover tok/s

  • 本地 verify 无 HTTP 开销（vs Path B 45ms/round）
  • Crossover 128 tok/s（Path B 仅 42）
  • M4 base 30-80 tok/s 在 crossover 以下
  • 预期加速 1.4-2.3x（BF16 batch=4）

鱼三：端侧跑大模型

26B

16GB Mac "感觉"能跑

  • 缓存命中 → 0.3ms（像本地）
  • 敏感代码 → 端侧 2B+MTP（不出域）
  • 非敏感 → 云端 EP8 26B（13ms）
  • 离线 → 降级 2B（不断服）

防御力不在单一技术，在于"时间窗 + 整合 + 定位"：

  1. 时间窗：Claude Code 后门事件 → 国产替代需求是现在，不是明年
  2. 整合复杂度：edge proxy + mTLS + SGLang EP8 + 多模型 + Hermes 路由 + MTP draft，完整系统不是 1-2 周能抄的
  3. 三鱼定位："低延迟 + 数据主权 + 大模型"三合一定位目前无竞品，先占住
  4. EP8 调优经验：CUDA_HOME/CCCL/flashinfer JIT 的坑是实测踩出来的，竞争者需要时间

这些是"时间窗"护城河，不是"永久"护城河。关键是在窗口期内拿到标杆客户。

十二、结论

CGC 三鱼模式的核心逻辑： 不试图在单一技术上建立护城河（proxy 三件套门槛低，我们承认）， 而是通过同一套技术栈服务三个独立的产品价值， 在竞品定位矩阵上占据一个目前无人占据的位置。

  • 鱼一（数据主权）：解决 B 端 #1 痛点，Hermes(SFT) 让 cache miss 也不破主权
  • 鱼二（推理加速）：本地 MTP crossover 128 tok/s，端侧 2B 加速 1.4-2.3x
  • 鱼三（跑大模型）：16GB Mac 用户"感觉"26B 就在本地，三层叠加消除延迟感知

技术栈不变——MTP Draft（llama.cpp 路径，149.8 tok/s）+ Hermes(SFT) + Edge Proxy + EP8—— 但产品价值是三维的。这不是技术护城河，是"定位 × 时间窗 × 整合度"的组合护城河。

Claude Code 后门事件创造了国产替代的时间窗。CGC 需要在窗口期内完成 Phase 1-2， 拿到 1-2 个标杆客户，占住"低延迟 + 数据主权 + 大模型"的三合一定位。 从代码补全切入，逐步扩展到通用 AI 推理市场。
