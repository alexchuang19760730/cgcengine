§3 對齊 A/B：設計（differ-by-one 是什麼意思）

先前那兩組數字要嘛條件不同、要嘛不是同一支臂。缺的不是資料，是那一支臂。 所以本輪只做兩件事：

  1. 在 scripts/check/decode_sweep.py 的臂表新增 orn-p25： 它的定義是 p25-gputime（＝ Nail ＋ CGC_SERVER_MTP=0 ＋ CGC_GPU_TIMING=1 ＋ CGC_DECODE_PROFILE=1）的逐字複本， 只加一個鍵 CGC_SERVER_MODEL 指向 Ornith。
  2. 跑 ABBA：前向 --arms p25-gputime,orn-p25，反向 --arms orn-p25,p25-gputime，其餘參數完全相同。

為什麼要「只差一個鍵」：先前那組 Ornith 數字來自 en-dc-orn-* 兩臂， 而它們還帶著 CGC_DOWN_COMBINE／CGC_DOWN_COMBINE_AUDIT （那是為 down-combine 融合實驗準備的）。帶著那兩個鍵的臂不能與 p25-gputime 配對 —— 那會變成「兩個變數」而不是單變數。這個 repo 已經有一條座右銘： 「兩次量測之間只有一個產物不同」不等於單變數實驗，前提是交錯。

另一個被刻意保留的鍵：CGC_SERVER_MTP=0 兩臂都設。理由是 MTP-on 會把 trunk 變成 verify 圖（n_tokens 2/4），那與「換模型」是兩個不同的問題；先把它固定住， 「換模型」才是單變數。

§6 decode 到 25 的算術

§6.1 恆等式，與 25 的出處

t/s  ＝  步速（steps/s）  ×  每步 token 數

「25 t/s」在本 repo 有出處：09-05 的 27.71，而它是 3.99 token/step ÷ 144 ms/step。換算成步速只有 6.94 steps/s —— 比今天慢 1.57×（今天 llama-bench 暖平台 10.78／10.91／10.98）。 ⇒ 那個數字幾乎全部住在「每步 token 數」那一項。我們曾經到過 25，但那不是靠步速。

§6.2 三個乘數的現況

乘數今天的值已量的槓桿要到 25 的缺口卡在哪
步速 ~10.9 steps/s（1 tok/step） CGC_SUBMIT_AHEAD：82.5 → 31–44 ms/步（×1.8–2.3） ×2.0–2.3 探針輸出損壞（其 16.82 t/s 不可引用）；S2／S3 的前提 B 已倒
每步 token 1.0（MTP off） MTP-on：9.82 → 12.62（×1.28） ×1.6–2.0 accept 58.25%（09-05 的 0.9974 是舊幾何的飽和值）
host 側 build 0.023 ＋ alloc 0.037 ＋ inputs 0.026
＝ 0.086 ms/步（0.07%）		 — 0 正式關閉（compute 佔 99.9%、fill_wait = 0.000）

§6.3 算術，與三個警告

12.62（MTP-on 實測）× 2.0（去序列化，未證）＝ 25.24
  1. 兩個乘數能不能相乘，還沒量過。12.62 與 31–44 ms/步是不同儀器量的 （llama-speculative-simple 與 HTTP 臂），兩者可能吃同一份空窗。 ⇒ 這個乘法是算術，不是計畫；要把它變成計畫，得在 MTP-on 的形狀下重量去序列化的天花板。
  2. 25 ÷ 10.9 ＝ 2.29×（不是 2.0×）。用 HTTP 臂的 12.24 算是 2.04×。交付口徑是 llama-bench 的 10.78–10.98，所以引用 25 的時候要指名口徑。
  3. n_predict=24 的短爆會給 18.7–20.3 的假希望（已判不可引用）。本輪刻意用 --n-predict 96，正是為了不落在那一格。

§6.4 該先做哪一件（判準已先寫死，順序不要換）

  1. 補 M3 缺的儀器（逐節點 GPU 時間，Metal counter sample buffer）。 判準：ffn_moe_* 佔 wait ≥40% ⇒ 有量；<15% ⇒ 三條路全不足、 走「找不到路」分支。沒有這個讀數，任何去序列化的實作都是學費（CGC_MMV_FUSE 的教訓）。
  2. 在 MTP-on 的形狀下重量去序列化的天花板 —— 這一步決定「兩個乘數能不能相乘」。
  3. MTP 的 accept：唯一已量到正增益、且不需要新儀器的槓桿。
  4. 不要算進 25 的預算：down-combine 融合對旗艦是 −15～18%；換成 Ornith 是 −1.49×。
  5. M1 的離開條件沒有一條被系統性重核 ⇒ M3／M4 站在未驗收的地基上。
