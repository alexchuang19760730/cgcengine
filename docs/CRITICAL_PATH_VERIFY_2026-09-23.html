📏 關鍵路徑是什麼？
在 speculative decoding 裡：
→ 每一步 = 跑 draft k 次 + 跑 verify 1 次
→ verify 這次 forward pass 就是關鍵路徑
→ draft 可以跑在背景，但 verify 必須跑完才算完

所以：decode 速度 = k / verify_step_time
→ verify 跑多久，決定了 decode 多快
→ 不是 draft 跑多久
→ 不是 MoE gather 跑多久
→ 是「整個 verify forward pass」跑多久
