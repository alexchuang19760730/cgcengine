④ 怎麼把一個離線端接進來

鴻蒙端與 Windows 端目前不在我們的網路上 ⇒ 沒有任何即時協議能成立。 唯一在它們真的離線時仍然成立的機制是 store-and-forward：端點寫檔，靠既有通道帶回來。
# 在端點上跑（只需 Python 標準函式庫；沒有這個 repo 也能跑）
python3 agent_harness/portal/report_endpoint_status.py --id windows-rtx4090 \
    --what-ran "建 CUDA 版（GGML_CUDA=ON）" --metric decode_tps=52.3 \
    --not-measured "沒量過 M1/M2/M3 身分"

# 讓它落到 endpoints/ 之後，靠既有通道帶回來：
#   鴻蒙端  scp ＋ ssh          → deploy-harmonyos/deploy-to-harmonyos.sh
#   Windows git（自動 push）    → agent_harness/scripts/auto_git_push.ps1
#   雲端    rsync               → CGC-main/cgc_engine/tools/_archive_v1/server/sync_all_gates_to_hosts.sh
# 若端點真的連得上，也可以直接 POST 給本入口：
#   curl -X POST http://127.0.0.1:8787/api/report -d @endpoints/windows-rtx4090.json
兩個對齊問題（不說就會靜默失敗）
① auto_git_push.ps1 推的是 branch fusionroutemot，而本入口讀的是 demo/sweet-spot-windows-fix ⇒ 兩邊對齊之前 Windows 的上報不會出現在這裡。

⑤ 這一頁的可信度邊界

  • 本頁顯示的閘門綠燈是「最後一次實跑」的記錄，不是剛剛跑的 —— 引擎面入口（build_portal.py --gates-only）才是跑閘門的地方。
  • 心跳探測的失敗一律寫 unknown，不是紅燈：連不上只說明「現在不知道」。
  • 能力的每一條都指到真實檔案裡的子串（見卡片下的 ↳ 行）—— 指針失效會讓 --check 變紅，不會靜默。
  • 本輪 --no-net：<b>沒有探測任何心跳</b>，所以「心跳可達」顯示 0 是「沒問過」而不是「不通」。
