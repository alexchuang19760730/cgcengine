⑤ 這一頁的可信度邊界

  • 本頁顯示的閘門綠燈是「最後一次實跑」的記錄，不是剛剛跑的 —— 引擎面入口（build_portal.py --gates-only）才是跑閘門的地方。
  • 心跳探測的失敗一律寫 unknown，不是紅燈：連不上只說明「現在不知道」。
  • 能力的每一條都指到真實檔案裡的子串（見卡片下的 ↳ 行）—— 指針失效會讓 --check 變紅，不會靜默。
  • 本輪 --no-net：<b>沒有探測任何心跳</b>，所以「心跳可達」顯示 0 是「沒問過」而不是「不通」。

⑥ 區網（LAN）—— 端側在同一個網段上連得到嗎

把「這台機器在區網上的位址、每個 harness 服務綁在哪個位址、要不要認證、同網段還有誰、哪些埠是別人的」寫成一份可機檢的註冊表。它回答的是 fleet.json 回答不了的那一半：fleet.json 說『機隊有誰』，join.json 說『還沒進來的要怎麼進來』，lan.json 說『同在一個網段上，連得到嗎、從哪裡連』。（本輪有實測綁定，timeout 0.5s）
