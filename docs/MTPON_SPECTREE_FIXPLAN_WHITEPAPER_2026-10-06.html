一句話。 A–D 這四條路徑作為集合是對的、沒有漏掉大條的；但排序需要改：
① A 不是「第一步」，它是已證的地板（~11 t/s ＝ 打平 OFF，不會到 25）——保留當 opt-in 預設，不當進度；

③ 因此把 B 改成 B′（先做便宜的「draft 耦合／位置消融」診斷，再決定改哪一行），並把它排在 C 前面；
④ C 仍是回到 20+ 的唯一 code 路徑，且本輪 already 找到一個具體入口（rep 邊界 draft-ctx 位置洩漏）；
⑤ 另補一條不在 A–D 表上、但儀器已就位的便宜實驗：k=1 四列樹（§6.2），它單獨可判「6 列形狀本身」這個假說。
⇒ 建議序：A（維持）→ B′（診斷＋修）→ k=1（同 session 搭車）→ C → D。
