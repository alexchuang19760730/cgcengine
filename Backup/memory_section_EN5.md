## §EN-5. 統一定案：`prefill250` ＋ `CGC_SPAC=1`（2026-09-16 19:0x）—— 否證實驗通過

`Backup/run_unified_ab.sh`，交錯 **A/B/A/B**，每臂**等散熱回 NOMINAL**，
`-b 512 -ub 512 -p 0 -n 128 -d 0,512 -r 3`。A=`prefill250`（SPAC 關）、
B=`prefill250:CGC_SPAC=1;CGC_SPAC_ALPHA=0.75`。

| 臂 | d0 | d512 |
|---|---|---|
| A1 / A2（SPAC 關） | 9.56 ±0.84 ／ 8.27 ±2.31 | 9.25 **±2.97** ／ 9.25 **±2.97** |
| B1 / B2（SPAC 開） | 9.79 ±1.02 ／ 9.60 ±1.00 | **10.78 ±0.04** ／ **10.91 ±0.47** |
| 配對中位（B−A） | **+0.78（+8.7%）** | **+1.60（+17.2%）** |

**兩件事同時成立，第二件比第一件重要：**

1. **d512 的均值 +17%**（配對 +1.53／+1.66，兩次同向）。
2. **d512 的離散從 ±2.97 崩到 ±0.04／±0.47** —— 逐 rep 反推：A 是 **6.28–12.21（1.94×）**，
   B 是 **10.74–10.82（0.7%）**。**SPAC 不是把均值推上去，是把「decode 工作集不駐留」造成的不穩定拿掉**，
   這正是 prod25 註解說的那件事。**在 d0 上兩臂重疊**（A2 自己的 reps 就 5.95–10.58）⇒
   **只有 d512 是決定性的。**

**⇒ 我寫下的否證條件（「若 SPAC=1 明顯較慢就改成 `prod25-stream`」）沒有成立 ⇒ 統一定案：**

**一個 profile：`prefill250` ＋ `CGC_SPAC=1`（alpha 0.75）。**
量測形狀由「量什麼」決定：prefill 用 profile 的 `-b/-ub 5632`；decode/depth 矩陣用 `-b 512`。

**暖值交叉驗證（三個獨立量測）**：09-15 `prod25-stream` **10.79**、今天 `prod25-stream` **10.89**、
今天 `prefill250+SPAC` **10.78／10.91** ⇒ **這台引擎的 llama-bench 暖 decode ≈ 10.8–10.9 t/s**。

### 順手釘住的一個方法學事實：llama-bench 沒有 `srand`

`llama-bench.cpp` 只有 `std::rand()`（四處），**沒有 `srand`** ⇒ 用 C 函式庫的預設種子 ⇒
**每一次跑的 token 流逐位相同**。指紋：A1 與 A2 的 d512 **均值與標準差都一樣**（9.25／2.97）。
兩個後果：
- **好**：A/B 的工作負載完全相同，只剩時序差異 ⇒ 對比乾淨。
- **壞**：它不是「一個隨機流」，而是**一個固定的偽隨機流**，`§W` 說的「與被服務的請求不同」
  是**系統性**的差異，不是抽樣假象。

### 保留（仍未量）

- `SPAC_ALPHA=0.75` 是在 ctx 4096 調的；**ctx 8192 可能要重調**。
- ctx 8192 對 decode 駐留的影響未量。
- 這次只有一組 depth（0,512）、一個 prompt、一個 reps 數 ⇒ 不是完整矩陣。
- 四臂發射都是 NOMINAL，但**臂內**漂移（A1 有 133/200 個 MODERATE）⇒ 絕對值略遜於全 NOMINAL 矩陣；
  不過 A1 是漂移最多的那一臂、數字卻不是最低的，所以漂移不是這次對比的主因。
