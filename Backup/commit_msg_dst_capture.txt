① §9.18.6：把一個「排除法」變成量測，結果推翻了那個論證
================================================================================

§9.18.4 的推理是：layer 1 的 gate/up/down ids 相同 + layer 2 的 router ids 不同 ⇒ layer 1 的
MoE 輸出不同 ⇒ ids 指向的權重內容不同 ⇒ 載體是池／slot 的內容（§9.18.7 因此主張「要修的是
residency」）。整條掛在第三步上，而第三步從來沒被量過。本 commit 把它量出來。

儀器：`CGC_TENSOR_CAPTURE=<精確節點名>`（＋`_WORDS`，預設 32）。
  讀 kernel_cgc_ids_capture 的原始碼會發現它與 ids 無關，就是「把 stride 個 int32 從 buffer 1
  抄進 buffer 2 的第 N 個 slot」的通用內核 ⇒ 指向另一個 buffer 不需要新內核、新 kargs、新 pipeline。
  改到的：ggml-metal-ops.cpp（cgc_submit 共用提交體、cgc_dst_capture、init 擴充、seq 合併）、
  ggml-metal-ops.h（註解）、scripts/run_server.sh（allowlist 三行）。
  沒改到：ggml-metal.metal、ggml-metal-impl.h、ggml-metal-device.{h,cpp,m}、ggml-metal-context.m。
  比較器 scripts/check/ids_capture_diff.py 原封不動可用。
  設計要點：精確名稱比對（substring 會命中 ffn_moe_down-10..-19）；獨立 slot 空間（ids 那條正好
  在 4096 上限，且它是比較器切 graph 的依據）；依提交序合併兩條流（否則 dst 列會落進最後一個偽
  graph，與什麼都比不到而被報成 IDENTICAL）。

★ 證據與結論
  同臂對照（同一臂跑兩次、互比）:
      無屏障  ids 120 SAME / 0 DIFF   ffn_moe_down-1.dst  每個 graph 都 DIFF
      有屏障  ids 120 SAME / 0 DIFF   ffn_moe_down-1.dst  每個 graph都 SAME（兩臂各一組）
  機制：ids 運算元的生產者在很多節點之前（早已沉降），dst 的生產者是緊鄰的前一個 kernel，而這個
  fork 支援內核併發（ggml_metal_op_concurrency_reset → ggml_metal_encoder_memory_barrier）⇒
  copy 可能讀到該 buffer 的前一位佔用者。修法＝在診斷路徑上插一個屏障（不改任何數值）。

  跨臂（有屏障，兩次獨立重跑結論相同）:
      graph 1-3    ids 120 SAME / 0 DIFF     dst SAME
      graph 4-30   ids   6 SAME / 114 DIFF   dst SAME     <-- 6 個 SAME 正好是 layer 0 與 layer 1
      graph 31-35  ids   0 SAME / 120 DIFF   dst DIFF

  ⇒ layer 0 的 router ids 相同 ⇒ 兩臂處理的是同一個 token（排除「token 流分歧」的平凡解釋）。
  ⇒ layer 1 的 ids 與它的 MoE 輸出都逐位元相同。
  ⇒ §9.18.4 的前提是錯的，它的結論被推翻；§9.18.7「要修的是 residency」失去唯一的直接證據，
     降級為「未受支持」。
  ⇒ 新的定位：分歧在 layer 1 的 MoE 輸出之後、layer 2 的 router 之前。而 layer 1 的 MoE 輸出
     逐位元相同也意味著 layer 1 的 attention 輸出相同 ⇒ 候選收斂到 layer 2 的 attention 路徑
     （q/k/v、rope、KV 讀取）或 layer 1→2 之間的 norm／殘差。專家池的權重內容不再是候選。

  儀器的已知限制（白皮書 §6 有完整表）：cgc_dst_capture 只掛在 ggml_metal_op_mul_mat_id ⇒
  只能擷取 mul_mat_id 節點的輸出；固定 stride 32 words（輸出列是 2048 words）；
  屏障是唯一偏離「純觀察者」的地方。
